## Home page (placeholder)

For now the home page shows the system status: "The API and database are up." when everything
is working, or a message saying what's wrong (the database is unavailable, or the server can't
be reached) with a **Check again** button. Any address the app doesn't know shows a "Page not
found" page with a link back home.
