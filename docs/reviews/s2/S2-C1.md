## Outside the row's scope, and why

- **One foreign key named by hand.** The convention's name for
  `approval_request.requirement_revision_id` is 66 characters, over Postgres's 63, and
  `test_every_constraint_and_index_name_fits_postgres_identifiers` fails on it. It's
  `fk_approval_request_requirement_revision_id` (the convention without the referred table); the
  schema doc says so, and `backend/CLAUDE.md`'s naming rule names the exception.
- **`activity_log`'s "action is updated, so a field is named" CHECK** is
  `ck_activity_log_updated_has_field`: the convention would name it after `field_changed`, which
  is already the enum CHECK's name.
- **A `StaleDataError` outside a request** (no `SessionDep`) now has no handler, so it's a 500;
  before, the app-wide handler answered it. Every session in `app/` comes from `get_session`
  except the CLI and the health check, which write nothing versioned. The developer guide says so.
