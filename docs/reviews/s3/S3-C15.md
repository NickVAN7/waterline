   at more than one membership. The two readings differ when an org admin creates a project with
   someone else as first admin (literally: ticked at once; the code: not yet), or when the creator
   later leaves (literally: still ticked; the code: unticked). Recommendation: the code's reading,
   with DL-201's wording and design-doc §11 changed to "a member besides its first admin".
2. **Inherited admins see the checklist.** "The project's admins" is read as §5's project admins,
   inherited ones included (as `project.update` already is). Recommendation: keep as is.
