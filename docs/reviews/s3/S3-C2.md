## Open questions for the owner

1. **Who counts as "project admin" in the transition table, for S3-C6 and S3-C7** (both
   reviewers). `may_transition` takes `is_project_admin` from its caller. On an
   export-controlled project, an inherited admin who also holds an explicit member or viewer
   membership passes the content gate, and `authorize()` grants them the admin content actions
   (`task.reassign_reporter`, `task.delete`), not `task.lower_restriction`. Recommendation: S3-C6
   and S3-C7 derive the flag through `authorize()` with `task.reassign_reporter` (an admin-only
   content action), so both paths compute it the same way and it agrees with every other
   admin content action; the alternative, an explicit project admin only on an
   export-controlled project, would need its own rule.
