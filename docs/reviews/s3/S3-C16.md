  the columns (S3-C0k); for anyone else only when a row on the page has an action.

  `clear()`), not a new wording; UI-TBL-10 says so.

  already holds that gap.

## After the report: the owner's finding

**The popover closed at once when Role was picked with the mouse** (owner, Nov 26, 2026). The
popover opened a microtask after the click that picked it; a browser runs microtasks between a
click's listeners, so PrimeVue's outside-click listener saw that click and closed it. The keyboard
path and jsdom's scripted clicks never showed it. Fixed in `fix(S3-C16)`: it opens after a
`setTimeout`. A mouse e2e (`a filter picked from Add filter with the mouse stays open…`, both
themes) failed before the fix and passes after; the trap is in `traps.md`. Verified by `wl check`
and `wl e2e workspace-admin` (14 passed); no reviewer re-ran.
