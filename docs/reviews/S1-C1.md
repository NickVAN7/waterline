1. **`audit_event` is append-only in the database:** no one can edit or delete an event.
   Built in the follow-up commit `fix(S1-C1)`: migration `de363d1a3629` adds the trigger
   `tr_audit_event_append_only`, which rejects every `UPDATE` and `DELETE` (SQLSTATE `23001`);
   tests for an SQL update, an ORM edit, and a delete, plus inserts still allowed; the enum CHECK
   tests now insert instead of update. Sabotage: with the trigger dropped, exactly the three
   guard tests failed. Design-doc §10.1, schema-doc `audit_event`, the developer guide, and the
   migration skill updated.
2. **`ClassificationMixin` stays in `core/`**, importing `app.enums`.
