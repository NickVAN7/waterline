## Owner answers to the review questions

1. **`direct_update` and `updated_at`:** rank writes leave `updated_at` alone; counter writes
   (e.g. adding a subtask) still move it. A parameter on `direct_update` controls it:
   **TD-7**, fixed in S0-C6.
2. **409 scope:** narrowed in S0-C6: 409 only for version conflicts; a zero-row update of a
   non-versioned entity (e.g. one hard-deleted meanwhile) is 404. Added to the build plan's
   Checkpoint 6 row.
3. **`session.get()` caveat:** the base repository's get-by-ID uses a query, never
   `session.get()`, so soft-deleted rows stay hidden: **TD-8**, fixed in Slice 1. Added to the
   build plan's "Backend architecture" (Repositories).
