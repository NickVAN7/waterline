## Owner decision during the checkpoint

1. **Migrations in the Compose stack.** The worker crashes on a database without
   procrastinate's schema (`ConnectorException`), so `wl up --wait` would fail on a fresh clone
   before `wl migrate` could run. **Decided:** a one-shot `migrate` service (the backend image,
   `alembic upgrade head`); `api` and `worker` start only after it succeeds. `wl migrate` runs
   that service. Recorded in the build plan ("Docker Compose") and the design doc's local-dev
   row.
